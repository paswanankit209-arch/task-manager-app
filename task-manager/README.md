# Taskflow — Advanced Task & Productivity Management App

A lightweight, distraction-free task management application built by **Ankit Paswan** with vanilla web standards and local browser persistence.

## Features
- **Zero Dependencies**: Pure HTML5, Modern CSS3 (Grid & Flexbox), Vanilla ES6+ JavaScript.
- **LocalStorage Persistence**: Automatically saves tasks and settings across sessions.
- **Productivity Metrics**: Real-time total, pending, and completed task counters with animated progress bar.
- **Categorization & Priorities**: Tag tasks with categories (Study, Coding, Project, Personal) and priorities (High, Medium, Low).
- **Search & Filters**: Instant full-text search, status tab filters (All, Pending, Completed), and sorting (newest, priority, due date).
- **Edit Modal**: Built with native `<dialog>` element and accessible keyboard focus traps.
- **Data Export & Import**: Backup and restore your tasks to/from clean JSON files anytime.
- **Dark & Light Mode**: Seamless theme toggle synced with your system preferences.

## Running Locally
Simply open `index.html` in any modern web browser or run with any static server:
```bash
npx serve .
```
