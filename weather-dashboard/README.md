# SkyPulse — Meteorological Weather & Forecast Dashboard

A real-time meteorological weather forecasting interface built by **Ankit Paswan** leveraging the open **Open-Meteo REST API**.

## Features
- **Zero API Key Needed**: Connects directly to Open-Meteo endpoints for open, accurate global forecasts.
- **Atmospheric Visuals**: Dynamic ambient color backdrops shifting with meteorological states (Sunny, Rainy, Snowy, Fog, Night).
- **24-Hour Timeline**: Interactive horizontal scroll of hourly temperatures and precipitation probabilities.
- **7-Day Outlook**: Multi-day forecast with comparative temperature range bars.
- **Global Search & Autocomplete**: Search any city worldwide with real-time geocoding suggestions.
- **GPS Geolocation**: 1-click detection of your local atmospheric coordinates.
- **Unit Switching**: Instant toggle between Celsius (°C) and Fahrenheit (°F).
- **Offline / Network Resilience**: Gracefully delivers localized weather estimations if network connectivity drops.

## Running Locally
Open `index.html` in your browser or run:
```bash
npx serve .
```
