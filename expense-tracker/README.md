# SpendWise — Personal Finance & Expense Tracker

A comprehensive personal finance and expense analytics web interface created by **Ankit Paswan** with vanilla JavaScript and client-side browser storage.

## Features
- **Net Balance & Cash Flow**: Real-time calculations of total income, expenses, net balance, and savings percentage.
- **Categorized Breakdown**: Visual donut chart created using pure CSS `conic-gradient()` and category progress bars with percentage share.
- **Multi-Currency Support**: Switch on the fly between INR (₹), USD ($), EUR (€), and GBP (£).
- **Transaction Ledger**: Instant search filtering, type toggles (All, Expense, Income), category filters, and deletion.
- **CSV Data Export**: 1-click download of your entire financial ledger into standard CSV format for Excel/Google Sheets.
- **Zero Third-Party Trackers**: 100% private and offline-capable using the browser's `localStorage` API.
- **Editorial UI**: Cohesive dark/light themes adhering to the developer portfolio styling.

## Running Locally
Open `index.html` in your browser or run:
```bash
npx serve .
```
